# Eco-Reto: Acciones Ecológicas 
Es una aplicación web desarrollada para registrar, consultar, editar 
y eliminar acciones que ayudan al planeta ,
migrada de SQLite a una base de datos en la nube. 

# Tecnologías utilizadas 
* **Fronted:** HTML5, CSS3, Jinja2, JavaScript 
* **Backend:** Python, Flask 
* **Base de datos:** PostgreSQL (alojada en Neon)
* **Despliegue y Hosting:** Render
* **Control de versiones:** Git y GitHub

# Enlace público 
Puedes probar la aplicación en línea a través del siguiente enlace en Render:
* https://ecoreto-7tl0.onrender.com *

# Instrucciones generales 
1. Clonar el repositorio desde GitHub
2. Instalar las dependencias ejecutando `pip install -r requirements.txt`.
3. Configurar la variable de entorno local `DATABASE_URL` con los datos de conexión a Neon.
4. Iniciar la aplicación en el entorno local o de producción.
